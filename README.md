## 📖 Sobre o Diretório `/prompts`

Bem-vindo ao diretório central de **Prompts para Agentes de IA**! 

Este repositório armazena uma coleção avançada e curada de instruções de sistema (System Prompts). O objetivo é configurar, moldar e dar vida a diferentes "personalidades" e "modos de operação" para Large Language Models (LLMs), otimizando o fluxo de trabalho de desenvolvimento de software.

Desenvolvido com base nas melhores práticas de Engenharia de Prompts (Prompt Engineering) e focado em produtividade real para pessoas desenvolvedoras.

---

## 🗂️ O Panteão de Agentes (Modos Disponíveis)

Cada prompt nesta pasta foi cuidadosamente construído para executar um papel específico no ciclo de vida de desenvolvimento. Aqui estão os modos que você encontrará:

| 🎭 Modo de Operação | 📁 Arquivo | 🎯 Objetivo Principal | 💡 Personalidade |
| :--- | :--- | :--- | :--- |
| **🔍 ASK Mode** | `prompt_ask.md` | **Leitura e Diagnóstico:** Responde dúvidas, explica código e diagnostica erros sem alterar arquivos. Foco em análise profunda. | Analítica e resoluta |
| **📋 PLAN Mode** | `prompt_plan.md` | **Arquitetura e Planejamento:** Cria planos de implementação revisáveis, define escopo, arquivos afetados e riscos estruturais antes do código. | Estratégica e direta |
| **⚙️ AGENT Mode** | `prompt_agent.md` | **Execução e Implementação:** Transforma requisitos em mudanças reais de código. Foco na entrega de código limpo e arquitetura sólida. | Técnica e precisa |
| **📚 STUDY Mode** | `prompt_study.md` | **Tutor Técnico:** Focado no aprendizado profundo (teoria, conceitos, trade-offs e prática). Explica do básico ao avançado com checkpoints. | Didática e paciente |

## 🛠️ Stack Tecnológica Alvo

Embora os prompts sejam altamente adaptáveis para qualquer linguagem, eles estão inicialmente calibrados e otimizados para o seguinte ecossistema:

* **Frontend/Mobile:** `Flutter`, `Dart`
* **Backend/Database:** `MongoDB`
* **Princípios Exigidos pela IA:** *Clean Architecture, Injeção de Dependências, SOLID, Tratamento de Erros e Alta Performance.*

## 🚀 Como Utilizar Estes Prompts

Para extrair o máximo de poder computacional desses agentes, siga os passos abaixo:

1. **Escolha a Ferramenta:** Você pode usar estes prompts em IDEs com IA integrada (Cursor, Windsurf, GitHub Copilot) ou interfaces de chat tradicionais (Gemini, ChatGPT, Claude).
2. **Copie as Instruções:** Abra o arquivo `.md` correspondente ao modo que você precisa para o seu momento atual.
3. **Configure o Sistema (System Prompt):** * *No Chat:* Cole o prompt como a primeira mensagem para calibrar o contexto da IA.
   * *Nas IDEs:* Adicione o conteúdo no arquivo de regras globais do seu projeto (ex: `.cursorrules` ou `.windsurfrules`).
4. **Inicie o Trabalho:** Interaja normalmente. Se precisar alterar a abordagem (de planejamento para execução, por exemplo), basta trocar o modo do agente.

## 🧠 Arquitetura de um Prompt de Alta Qualidade

Todos os prompts deste repositório seguem uma arquitetura rigorosa de Engenharia:
- **Identidade e Missão:** O papel exato que o agente deve assumir.
- **Definição de Stack:** O contexto tecnológico estrito para evitar alucinações da IA.
- **Personalidade ("J.A.R.V.I.S."):** O tom de voz calibrado para manter as interações elegantes, objetivas e livres de distrações visuais (sem emojis excessivos).
- **Regras Operacionais (Guardrails):** Limites claros do que o agente *deve* fazer e o que é terminantemente *proibido*.
- **Formato de Resposta Obrigatório:** Padronização da saída para garantir leitura rápida.
